How a private transfer works
3 steps
01
Deposit a fixed denomination
Funds enter the pool for that asset and denomination. A secret note is generated for you to store.
02
Let the anonymity set grow
Wait for maturity and for more same-denomination deposits to join. A larger set means stronger privacy.
03
Withdraw with the note
Generate a proof and use a relayer to submit the withdrawal. The relayer cannot see the note or control funds.
